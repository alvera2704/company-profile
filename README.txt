ALVÉRA — CAT CELEBRATIONS WEBSITE

Isi folder:
- index.html      : halaman Home
- about.html      : halaman About Us
- css/style.css   : seluruh desain dan responsive styling
- js/script.js    : menu mobile dan tahun footer

Cara menjalankan di VS Code:
1. Ekstrak ZIP ini.
2. Buka folder `alvera-cat-company` di VS Code.
3. Klik kanan `index.html` lalu pilih Open with Live Server (jika ekstensi Live Server sudah terpasang).
   Alternatif: buka file index.html langsung di browser.
4. Klik menu Home dan About Us untuk berpindah halaman.

Catatan:
- Foto pada desain menggunakan URL gambar Unsplash sehingga perlu koneksi internet.
- Email pada halaman About memakai alamat contoh `hello@alvera.example`. Ganti dengan alamat email milikmu jika sudah ada.
- Semua teks, warna, foto, dan detail layanan bisa diedit di file HTML/CSS.
